# Just One Cat

Just one cat and one cat fact per day. Every day.

Live at: [cats.jantokarzewski.pl](https://cats.jantokarzewski.pl)

## How it works

Starting from November 13, 2026 (`0000.webp`), the page serves a new cat photo and cat fact each day. Once it goes through all 9,936 photos (and 734 facts), it loops back to the start.

## Development

Install dependencies and build the CSS:

```bash
npm install
npm run build
```

Watch for changes while editing:

```bash
npm run dev
```
